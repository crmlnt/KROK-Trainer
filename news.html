DATABASE REVIEW

Database Quality Review — Phase 1 Complete

Phase 1 of the KROK 1 database quality review has been completed, covering the 2007–2017 question sets.

Questions and answer keys were systematically cleaned, compared and validated against external reference material using a conservative review process. Medical answer-key discrepancies are never corrected automatically and remain subject to source verification and manual review.

  • 492 validated SAFE text corrections.
  • 1,944 questions compared with reference material.
  • 1,451 answer keys evaluated.
  • No unauthorized or structural database changes detected.
  • Phase 1 — 2007–2017 completed.
  • Phase 2 — 2018–2023 next.

18 AUG 2026
DATABASE REVIEW

Database Quality Review in Progress

We have started a systematic review of the KROK Trainer question database to improve both question quality and answer-key accuracy.

An initial audit of 300 questions from the 2020 and 2023 datasets identified several entries requiring further review, including possible OCR/text errors and potential answer-key discrepancies.

These findings are currently being manually verified against reference material before any changes are made to the database. No unverified medical corrections are applied automatically.

  • 300 questions included in the initial audit.
  • Question wording and answer keys are reviewed separately.
  • Potential discrepancies require verification before correction.
  • The original database is preserved during the review process.
